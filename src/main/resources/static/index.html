sql-mask · SQL 脱敏改写

基于 Apache Calcite 的 PostgreSQL SQL 脱敏改写 —— 表结构、列策略、策略定义均可在线编辑，不连接数据库、不执行 SQL

表和列来自「表结构」，策略来自「策略定义」
参数为按顺序排列的标量，逗号分隔，如 3, 4 或 'a', true, 1.5
修改尚未应用
SQL 语句 支持多条，以 ; 分隔；仅接受 SELECT / WITH … SELECT
dialect: postgresql
