# sql-mask 功能清单 v2（arch-v2 重构后）

> 基线：feature/arch-v2 分支（重构自 main @ 448c280）。对照基线见 `docs/baseline-inventory-20260924.md`。

## 1. 架构总览

**模块化单体 + 可嵌入内核**：

```
浏览器 ──(80)──► mask-server 单体（:8080，API + 控制台静态资源）
                  ├─ 元数据域 mask-metadata（实例/结构/采集/分类分级）
                  ├─ 策略域 mask-policy-admin（策略/UDF 中心/生效编译）
                  ├─ 查询网关 mask-query（Submitter SPI/护栏/放行开关）
                  ├─ 风控域 mask-risk（规则/告警/UEBA/阻断，进程内消费审计）
                  ├─ 审计域 mask-audit（jdbc/es/none 三存储，进程内风控转发）
                  ├─ 认证域 mask-auth（none/simple/ldap，集中 Bearer 门禁）
                  ├─ 授权域（mask-server 内,grants：模型/编译/矩阵）
                  └─ RewriteContextRepository（改写热路径:元数据快照+生效配置,零 HTTP）
                        ▼
                  mask-engine 内核（纯库,零 Spring,enforcer 强制,可嵌入查询引擎）
                  mask-sqlparser（Calcite 1.42 自研语法:INSERT OVERWRITE / TOP）
                  mask-policy（Ranger 式策略模型）
```

- 存储：**PG 默认 / H2 文件回退**，DDL 全部可移植（identity/TEXT,无 JSONB）。
- 旧 5 微服务（core/policy-server/metadata/query/risk-server）并为一体;CLI 保留（同 jar 双模）。

## 2. 改写内核（基础能力,全部保留）

- [x] 五方言 postgresql/trino/mysql/hive/sparksql;StarRocks 复用 mysql 并**默认放行 INSERT OVERWRITE**
- [x] 外层投影包裹改写,内层原文逐字节不动;SELECT/WITH/INSERT…SELECT/INSERT OVERWRITE/CTAS;UPSERT 拒绝
- [x] 血缘溯源 fail-closed;行过滤白名单+派生表注入+多条件 AND;多来源列策略 tie-break
- [x] **实例级方言能力开关**：`topN` / `insertOverwrite` 按实例覆盖(新)——`SELECT TOP (n)` 可在 pg 等方言启用
- [x] 全线 fail-closed;字节级 TPC-DS golden 回归(432 引擎测试)
- [x] **实例级改写失败放行开关(新)**：`onRewriteFailure=PASSTHROUGH` 时纯读语句以原 SQL 继续,
      响应标 `rewrittenBypassed`,计数器 `sqlmask_query_rewrite_bypass_total`,审计留痕;写语句绝不放行
